Step 1 Of 4

Set Up Your Dashboard

Choose the basic dashboard behavior. Torrent Dashboard listens on 0.0.0.0 so it can be reached from your network.

Local Dashboard AddressAddress used to reach Torrent Dashboard from your network.
The local IP address is detected from this PC. Port changes take effect the next time Torrent Dashboard starts.
This is required only when the first setup is being performed from another device.
Step 2 Of 4

Protect Dashboard Access

Choose which network adapters are trusted. Every selected adapter contributes its current subnet, and you can add individual IP addresses or CIDRs to the whitelist.

Trusted Network InterfacesSelect one or more network interface cards. Their current subnets are trusted automatically.
Detecting Network Interfaces…
Loopback access on the host is always trusted. Interface selections follow the actual subnet assigned to each NIC, so DHCP address changes do not require editing the whitelist. The manual list accepts a single IP or a CIDR on each line.
Step 3 Of 4

Add Your Download Client

Torrent Dashboard connects to qBitTorrent through its Web API. API Key authentication is preferred on qBitTorrent 5.2+; Username and password remain available for older versions.

Generate it in qBitTorrent → Preferences → Web UI → API Key.
Not Tested Yet
If qBitTorrent runs on the same PC as Torrent Dashboard, keep 127.0.0.1:8080. Remote users connect to Torrent Dashboard on port 8765; qBitTorrent itself does not need to be exposed to the LAN.
Step 4 Of 4

Review And Finish

Torrent Dashboard will re-test qBitTorrent once more, save the settings, and start collecting torrent status.

You can add additional qBitTorrent instances, notifications, integrations, themes, trusted interfaces, and whitelist entries later under Settings.
